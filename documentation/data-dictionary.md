# Data Dictionary

The `Sales_Data` worksheet contains 1,000 order-level records and 21 fields.

| Field | Description |
|---|---|
| `Order_ID` | Unique order identifier |
| `Order_Date` | Date the order was placed |
| `Customer_ID` | Customer identifier |
| `Customer_Segment` | Customer classification or segment |
| `Category` | Product category |
| `Product` | Product name |
| `Region` | Sales region |
| `Sales_Channel` | Channel through which the order was placed |
| `Payment_Method` | Payment method used |
| `Quantity` | Units ordered |
| `Unit_Price` | Price per unit |
| `Discount_%` | Discount percentage |
| `Gross_Sales` | Sales amount before discount |
| `Discount_Amount` | Discount amount |
| `Revenue` | Revenue measure used in workbook summaries |
| `Order_Status` | Order status |
| `Shipping_Type` | Shipping or delivery type |
| `Customer_Rating` | Customer rating associated with the order |
| `Profit_Margin_%` | Profit margin percentage |
| `Net_Sales` | Sales after discount, as defined in the workbook |
| `Profit` | Profit amount |

Descriptions are based on field names and workbook usage. Confirm formal business definitions and currency with the dataset owner before external reporting.
